# Správa nemovitostí

Webová aplikace pro správu vlastních i spravovaných nemovitostí: nájmy, kontrola plateb (Fio API),
upomínky (SMS / WhatsApp / e-mail), energie a vyúčtování služeb, náklady, výnosnost, dokumenty
a automatizace nájemních smluv.

- Databáze: Supabase (PostgreSQL, EU) – schéma v `supabase/migrations/`
- Aplikace: Next.js, nasazení na Vercel
- Připraveno pro více organizací (správců); zatím interní použití
